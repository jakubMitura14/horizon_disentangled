Stage 1: Building the Bedrock of Clinical Validity with Supervisor Models

Input Data

3D Images (MRI, PET, CT), Clinical Data (EHR), Histopathology (WSI)

Supervisor Models

  • Ordinal Classifiers: For PI-RADS, TNM Stage. Uses a differential ordinal loss to understand clinical order.
  • Censored Survival Regressor: For Time-to-Progression (TTP). Handles right-censored data using censored regression and ranking losses.

Output

Strong, clinically-validated signals (predictions for TNM, TTP, etc.) to guide the generative models.

Stage 2: Mastering Heterogeneity through Principled Disentanglement

Hierarchical VAE Architecture

A separate VAE is trained for each imaging modality to learn a disentangled latent space.

Latent Space Partitioning

The latent space is partitioned into four independent, semantically meaningful components:

  • $Z_A$: Anatomy
  • $Z_D$: Disease
  • $Z_P$: Patient State
  • $Z_S$: Style/Confounders

Composite Loss Function

$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{VAE}} + \lambda_A \mathcal{L}_{\text{Anatomy}} + \lambda_D \mathcal{L}_{\text{Disease}} + \lambda_I \mathcal{L}_{\text{Disentangle}}$

Uses targeted penalization (Total Correlation) to enforce statistical independence between specific subspaces (e.g., Disease vs. Style).

Output

Purified latent vectors representing the core components of the patient's state, stripped of technical artifacts.

Stage 3: VAE-based Out-of-Distribution Detection for Label Noise Resilience

OOD Detection Goal

Identify and flag atypical or potentially mislabeled data points for expert review to improve dataset quality.

Methodology

  • Learn Normality Manifold: A secondary VAE is trained on the latent space representations ($Z_D, Z_P$) to model the distribution of "normal" data.
  • Quantify Deviation: OOD samples are identified using high reconstruction error and large latent space distance (KNN-based).

Output

A cleaner, more reliable training dataset, leading to a more robust and trustworthy final AI model.

Stage 4: Capturing Disease Dynamics with Neural Jump ODEs

Input

Time series of sparse latent state vectors ($\mathbf{v}(t_i)$), including $Z_D$ and $Z_P$ from Stage 2.

Neural Jump ODE (NJDE) Model

Models disease evolution as a hybrid system:

  • Continuous Evolution (NODE): Models smooth progression between events. $\frac{d\mathbf{v}(t)}{dt} = f(\mathbf{v}(t), t; \psi)$
  • Discrete Jumps (Interventions): A separate network models instantaneous changes from therapies. $\mathbf{v}^+ = g(\mathbf{v}(t_k), \text{intervention}_k; \phi)$

Training Strategy

  • Pre-trained on a rule-based algorithm derived from EAU guidelines.
  • Fine-tuned on real data using a masked loss function to handle missingness.

Output

A learned, dynamic model of the patient's disease trajectory, capable of predicting future states.

Stage 5: Translating Insight into Action

Generative Synthesis

Generate high-fidelity counterfactual images for any time point or "what-if" scenario using the learned latent dynamics and a lightweight Diffusion Model for realism.

Treatment-Choice Helper

Simulate multiple future trajectories based on different treatment options to identify the optimal strategy for maximizing time to progression.

Structured Reporting

A Transformer-based decoder automatically generates structured reports integrating prognostic simulations, treatment comparisons, and data-driven recommendations.
