README for NHR Proposal Templates Version  9. October 2025

This archive contains the latex templates for the detailed descriptions for NHR compute time proposals. Before using, please check that you have the most recent version (This is version  9. October 2025). The most recent version can be found at https://go-nhr.de/computing-time.

They should build with pdflatex, xelatex and lualatex.

Included are the complied pdfs of the respective versions with included fill-out hints (..._with_hints.pdf) and without hints.

Before starting with the proposal please consider the possible simplifications, e.g. for already reviewed research projects or well-known codes (see https://www.nhr-verein.de/en/computing-time).
In case of any questions or problems, please don't hesitate to contact the center you want to apply for.

When to use which variant:

New proposal (word/NHR-Template_new.docx, latex/new_proposal.tex): 
  - For new NHR normal or large project proposals that are NOT extensions of existing projects. In case of NHR normal project proposals for already reviewed (whitelisted) research projects please check with https://www.nhr-verein.de/en/computing-time if the center you want to apply for allows the use of a simplified description (see simplified/whitelisted below.)

Extension of project (word/NHR-Template_extension.docx, latex/extension_proposal.tex):
  - For extensions of NHR normal or large projects. Such extensions are for one or multiple years. If you are looking for a short-term extension up to three months, please contact the NHR center instead. In case of NHR normal project proposals for already reviewed (whitelisted) research projects please check with https://www.nhr-verein.de/en/computing-time if the center you want to apply for allows the use of a simplified description (see extension simplified/whitelisted below.)
 
Simplified proposal for already reviewed research projects (word/NHR-Template_new_whitelisted.docx, latex/new_whitelisted_proposal.tex): 
  - For NHR normal project proposals for already reviewed (whitelisted) research projects. Please note that not all centers allow the usage of this simplified templated for whitelisted proposals. Please check at https://www.nhr-verein.de/en/computing-time.
 
Simplified extension for already reviewed research projects (word/NHR-Template_extension_whitelisted.docx, latex/extension_whitelisted_proposal.tex): 
  - For extension of NHR normal projects for already reviewed (whitelisted) research projects. Please note that not all centers allow the usage of this simplified templated for whitelisted proposals. Please check at https://www.nhr-verein.de/en/computing-time. Such extensions are for one or multiple years. If you are looking for a short-term extension up to three months, please contact the NHR center instead.
